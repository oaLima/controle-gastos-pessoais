# Controle de Gastos Pessoais

Aplicação desenvolvida em Python para registrar, organizar e analisar gastos pessoais por meio de uma aplicação executada no terminal.

O projeto começou como uma forma de aplicar conceitos fundamentais de Python em uma situação prática e evoluiu gradualmente conforme novos conceitos foram estudados.

## V2.0

A segunda versão representa uma evolução da primeira versão do projeto, adicionando novas análises, validações e uma melhor organização da lógica da aplicação.

### Funcionalidades

* Registrar descrição do gasto
* Registrar categoria
* Registrar valor
* Armazenar múltiplos gastos
* Exibir os gastos registrados
* Calcular o total de gastos
* Identificar o maior gasto
* Identificar o menor gasto
* Calcular a média dos gastos
* Calcular o total gasto por categoria
* Definir um orçamento mensal
* Calcular o valor restante do orçamento
* Validar entradas do usuário
* Tratar situações em que não existem registros

## Exemplo de funcionamento

A aplicação é executada diretamente pelo terminal e permite registrar os gastos e visualizar as informações calculadas pelo sistema.

### Registro dos gastos

```text
=== CONTROLE DE GASTOS ===

Categoria: Alimentação
Qual foi o valor: 50
Descrição: Mercado

Categoria: Transporte
Qual foi o valor: 25
Descrição: Uber

Categoria: Lazer
Qual foi o valor: 80
Descrição: Cinema
```

### Resultado

```text
=== RESUMO DOS GASTOS ===

Alimentação | R$ 50,00 | Mercado
Transporte  | R$ 25,00 | Uber
Lazer       | R$ 80,00 | Cinema

Total de gastos: R$ 155,00
Menor gasto: R$ 25,00
Maior gasto: R$ 80,00
```

> Os valores apresentados acima são apenas um exemplo de execução da aplicação.
